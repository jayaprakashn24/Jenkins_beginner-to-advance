# Day 2 - Running Commands in Jenkins

## Goal
Run shell commands inside a Jenkins pipeline

## Task
- Added a new stage
- Used `sh` to execute commands

## Pipeline Stages
1. Say Hello → prints message  
2. Run Command → executes shell commands

## Commands Used
- echo → prints text  
- pwd → shows current directory  
- whoami → Prints the username of the currently logged-in user.
- date → Displays the current system date and time, including timezone information. 
- df -h → Shows disk filesystem usage in a human-readable format (e.g., GB, TB), including total size, used space, available space, and mount points.


## Output
- Displays message , current working directory ,username ,current date , available disk space
